# 60 秒现场演示脚本 · LIVE DEMO

> 用于答辩 Slide 03 替代 demo.gif（更有现场感）
> 目标时长：**60 秒（±5 秒）**
> 风险等级：⚠ 中等（依赖网络 + Streamlit 不卡）
> 备用方案：如果现场出问题立即切回 demo.gif（PPT 已嵌入）

---

## 演示前准备（开场前 30 秒）

| 准备项 | 检查方式 |
|---|---|
| Streamlit 已启动 | 浏览器打开 [http://localhost:8501](http://localhost:8501) 看到主页面 |
| 真实数据已在 | 侧栏选「真实链上数据」，CSV 路径默认即可 |
| 字体放大 | Ctrl + ＋ 三次，让评委看清 |
| 浏览器最大化 | F11 进全屏（隐藏地址栏） |
| Streamlit 主题 | 默认浅色或深色都行（提前调好） |

**❗ 重要**：演示前一定先在侧栏点过一次「🚀 运行回测」，让看板**已经处于跑完状态**，演示时直接切 Tab 就能展示，不必等 spinner。

## 关键交互点

### 必须提前完成（开场前）

侧栏从上到下依次设置：

1. **数据源** → 真实链上数据
2. **策略预设** → 保守稳健（自动填好所有滑块）
3. **滑点档位** → 中（默认）
4. **运行回测** → 点击，等候 5 秒回测完成

然后回到侧栏底部的「策略管理」：

5. 输入 `保守稳健` → 点 **💾 保存当前结果**
6. 切预设到 **激进动量** → 运行 → 保存为 `激进动量`
7. 切预设到 **极端风险厌恶** → 运行 → 保存
8. 切预设到 **均衡** → 运行 → 保存
9. 切预设到 **低频价值** → 运行 → 保存

这样多策略对比 Tab 就有 5 个策略的数据了。最后回到 **概览 Tab** 等待开演。

### 演示中**不要做**的事

- ❌ **不要重新跑回测**——浪费时间且可能失败
- ❌ **不要调滑块**——评委看不清你在调什么
- ❌ **不要进入「成本」Tab**——表格信息密度高，60 秒讲不完
- ❌ **不要进入「行情」Tab**——4 张图都好看但讲完要 30 秒

### 万一卡住的应急

| 异常 | 处理 |
|---|---|
| Streamlit 转圈 | 等 3 秒，不行就 F5 刷新（损失约 10 秒） |
| 浏览器崩溃 | 立即 Alt+Tab 回 PPT，说"展示动画版本"，用 demo.gif 替代 |
| 网络断了 | 跳过真实数据演示，直接讲合成数据结果 |
| 投影分辨率有问题 | 提前 Ctrl+0 重置缩放后再 Ctrl++ 调整 |
